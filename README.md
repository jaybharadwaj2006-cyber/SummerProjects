# 📄 AI PDF Summarizer

An AI-powered PDF summarizer built using Python, Gemini AI, Tkinter, and PyPDF2.  
This project allows users to upload a PDF file and instantly generate:

- ✅ Concise Summary
- ✅ Important Bullet Points
- ✅ One-line Takeaway

The generated summary is displayed inside a clean scrollable GUI window.

---

#  Features

- 📂 Upload PDF files
- 🤖 AI-generated summaries using Gemini AI
- 🖥️ Simple Tkinter GUI
- 📜 Scrollable summary window
- ⚡ Fast and lightweight
- 🆓 Uses free Gemini Flash model

---

# 🛠️ Technologies Used

- Python
- Tkinter
- Google Gemini API
- PyPDF2
